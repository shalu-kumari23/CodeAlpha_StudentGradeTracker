# Student Grade Tracker

## Project Description

Student Grade Tracker is a Java-based console application that helps manage student records and marks. It calculates average marks, identifies the highest and lowest scores, and displays a summary report of students.

## Features

* Add and manage student marks.
* Calculate average marks.
* Find the highest and lowest scores.
* Display a summary report of students.
* Store and manage data using Java collections or arrays, depending on the implementation.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList or Arrays (as implemented in the code)

## Requirements

* Java Development Kit (JDK) installed
* A code editor such as VS Code, IntelliJ IDEA, or Eclipse

## How to Run

1. Clone or download this repository.

2. Open the project folder in your code editor.

3. Open a terminal in the folder containing `Main.java`.

4. Compile the program:

   ```bash
   javac Main.java
   ```

5. Run the program:

   ```bash
   java Main
   ```
